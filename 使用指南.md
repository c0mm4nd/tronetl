# 使用指南

本指南将详细介绍如何使用 `tronetl` 工具从 TRON 网络中提取各种数据。

## 1. 抽取交易数据 (外部交易)

您可以使用 `export_blocks_and_transactions` 命令来提取外部交易。

**命令:**
```bash
tronetl export_blocks_and_transactions \
    --start-block <起始区块> \
    --end-block <结束区块> \
    --provider-uri <节点地址> \
    --transactions-output transactions.csv
```

**输出文件 (`transactions.csv`):**

| hash | nonce | block_hash | block_number | transaction_index | from_address | to_address | value | gas | gas_price | input | block_timestamp | max_fee_per_gas | max_priority_fee_per_gas | transaction_type | status | transaction_timestamp | transaction_expiration | fee_limit |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |

**列说明:**
*   `hash`: 交易哈希
*   `from_address`: 发送方地址
*   `to_address`: 接收方地址
*   `value`: 交易金额 (sun)
*   `block_number`: 区块高度
*   `block_timestamp`: 区块时间戳 (秒)
*   `status`: 交易状态 (SUCCESS 或 REVERT)

---

## 2. 抽取内部交易

您可以使用 `export_token_transfers` 命令来提取内部交易。

**命令:**
```bash
tronetl export_token_transfers \
    --start-block <起始区块> \
    --end-block <结束区块> \
    --provider-uri <节点地址> \
    --internal-tx-output internal_transactions.csv
```

**输出文件 (`internal_transactions.csv`):**

| block_number | transaction_hash | internal_index | internal_hash | caller_address | transferTo_address | call_info_index | call_token_id | call_value | note | rejected |
|---|---|---|---|---|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |

**列说明:**
*   `transaction_hash`: 外部交易哈希
*   `caller_address`: 调用方地址
*   `transferTo_address`: 接收方地址
*   `call_token_id`: 代币 ID (空表示 TRX)
*   `call_value`: 转移的代币数量

---

## 3. 抽取合约数据

您可以使用 `export_address_details` 命令来获取合约的详细信息。

**输入文件 (例如, `addresses.csv`):**
```csv
address
T...
T...
```

**命令:**
```bash
tronetl export_address_details \
    --addrs-source addresses.csv \
    --contracts-output contracts.csv \
    --provider-uri <节点地址>
```

**输出文件 (`contracts.csv`):**

| address | bytecode | function_sighashes | is_erc20 | is_erc721 | block_number | contract_name | consume_user_resource_percent | origin_address | origin_energy_limit |
|---|---|---|---|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |

**列说明:**
*   `address`: 合约地址
*   `bytecode`: 合约字节码
*   `function_sighashes`: 函数签名哈希列表
*   `is_erc20`: 是否为 TRC20 合约
*   `is_erc721`: 是否为 TRC721 合约
*   `contract_name`: 合约名称

---

## 4. 抽取代币数据

您可以使用 `export_address_details` 命令来获取代币的元数据。

**输入文件 (例如, `token_addresses.csv`):**
```csv
address
T...
T...
```

**命令:**
```bash
tronetl export_address_details \
    --addrs-source token_addresses.csv \
    --tokens-output tokens.csv \
    --provider-uri <节点地址>
```

**输出文件 (`tokens.csv`):**

| address | symbol | name | decimals | total_supply | block_number |
|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... |

**列说明:**
*   `address`: 代币合约地址
*   `symbol`: 代币符号
*   `name`: 代币名称
*   `decimals`: 代币精度
*   `total_supply`: 总供应量

---

## 5. 抽取代币交易

### TRC10

使用 `export_blocks_and_transactions` 命令。

**命令:**
```bash
tronetl export_blocks_and_transactions \
    --start-block <起始区块> \
    --end-block <结束区块> \
    --provider-uri <节点地址> \
    --trc10-output trc10_transfers.csv
```

**输出文件 (`trc10_transfers.csv`):**

| block_number | block_hash | transaction_hash | transaction_index | contract_call_index | asset_name | from_address | to_address | value |
|---|---|---|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... | ... | ... | ... |

**列说明:**
*   `asset_name`: TRC10 代币名称
*   `from_address`: 发送方地址
*   `to_address`: 接收方地址
*   `value`: 交易金额

**命令:**
```bash
tronetl export_token_transfers \
    --start-block <起始区块> \
    --end-block <结束区块> \
    --provider-uri <节点地址> \
    --transfers-output token_transfers.csv
```

**输出文件 (`token_transfers.csv`):**

| block_number | transaction_hash | log_index | token_address | from_address | to_address | value |
|---|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... | ... |

**列说明:**
*   `token_address`: 代币合约地址
*   `from_address`: 发送方地址
*   `to_address`: 接收方地址
*   `value`: 交易金额
